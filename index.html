Native macOS menu bar utility

MacMode

One switch. DEV ◄──────────────► GAMING.

Stop digging through System Settings. Flip your Mac's Function Keys — and soon much more — from a single menu bar control.

Download for macOS · v0.1.0 GitHub

macOS 14+ · Apple Silicon & Intel · Free & open source (MIT)

How it works

  1. Pick a mode from the menu bar — DEV for work, GAMING for play. Add your own modes in Settings.
  2. Keys switch instantly — standard function keys for IDEs and debuggers, media keys when you just want brightness and volume.
  3. Verified, not assumed — every switch is confirmed against the live system before the UI claims success.

Available today

  • DEV / GAMING switch from the menu bar (one click)
  • Function Key behavior per mode, applied and verified live
  • Custom modes: add, rename, recolor, delete
  • Per-mode accent color across the UI
  • Mode persistence across restarts
  • No tracking, no network, no account — fully offline

Install

  1. Download the ZIP and unzip it.
  2. Move MacMode.app to /Applications.
  3. First launch: right-click the app → Open (v0.1.0 is ad-hoc signed; Developer ID notarization is planned).

Roadmap

Launch at Login, keyboard shortcut to switch, per-app auto-switching, display/audio profiles and more. Follow along on GitHub.
